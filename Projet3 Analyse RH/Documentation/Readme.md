# Projet 3 – Analyse RH

## 📌 Présentation du projet

Ce projet consiste à analyser les données des employés d'une entreprise afin de mieux comprendre la structure des effectifs, la rémunération et l'ancienneté.

L'objectif est de transformer des données RH brutes en **indicateurs et visualisations permettant d'aider la direction dans la prise de décision**.

---

## 🎯 Objectifs

Les principaux objectifs de cette analyse sont :

* Analyser la répartition des employés par département, ville, poste et genre.
* Calculer les principaux indicateurs RH.
* Étudier les niveaux de rémunération.
* Analyser la masse salariale.
* Étudier l'ancienneté des employés.
* Identifier les principales tendances RH.
* Construire un dashboard interactif avec Power BI.

---

## 📊 Données utilisées

Le fichier source contient **30 employés** avec les informations suivantes :

* ID employé
* Nom
* Prénom
* Genre
* Département
* Poste
* Date d'embauche
* Salaire
* Ville

Les données concernent plusieurs départements, notamment :

* Informatique
* Finance
* Commercial
* Logistique
* Marketing
* Production
* Ressources Humaines

---

## 🧹 Nettoyage et préparation des données

La préparation des données a été réalisée avec **Power Query**.

Les principales étapes ont été :

* Vérification des types de données.
* Suppression des espaces inutiles.
* Vérification des doublons sur les identifiants employés.
* Vérification des valeurs nulles.
* Création de l'année d'embauche.
* Calcul de l'ancienneté.
* Harmonisation de certaines valeurs textuelles, notamment les noms de départements et certains intitulés de postes.

Les données nettoyées ont ensuite été chargées dans Excel et Power BI.

---

## 💡 Principaux résultats

L'analyse montre que :

* **L'Informatique** possède le plus grand effectif avec 6 employés.
* **L'Informatique** présente également le salaire moyen le plus élevé parmi les départements, avec environ 435 833 FCFA.
* **Dakar** concentre la majorité des employés avec 20 employés sur 30.
* La répartition globale entre les femmes et les hommes est équilibrée : **15 femmes et 15 hommes**.
* La masse salariale est fortement concentrée à Dakar.
* Le salaire moyen augmente avec l'ancienneté dans cet échantillon.
* Les employés ayant entre 2 et 3 ans d'ancienneté représentent la plus grande partie de l'effectif.
