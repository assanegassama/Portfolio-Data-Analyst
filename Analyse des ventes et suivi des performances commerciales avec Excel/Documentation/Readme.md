# 📊 Projet 1 — Analyse des ventes avec Excel et Power Query

## 🎯 Présentation

Ce projet consiste à analyser les données commerciales d'une entreprise afin de comprendre ses performances de vente et d'identifier les principaux facteurs contribuant au chiffre d'affaires.

L'analyse a été réalisée avec **Microsoft Excel** et **Power Query**, depuis la préparation des données jusqu'à leur visualisation et leur interprétation.

## ❓ Problématique

Comment exploiter les données commerciales pour identifier les performances des ventes et fournir des informations utiles à la prise de décision ?

## 🛠️ Outils utilisés

* **Microsoft Excel**
* **Power Query**
* Tableaux croisés dynamiques
* Graphiques Excel

## 📂 Données

Le projet utilise trois principales tables :

* **Clients**
* **Produits**
* **Ventes**

Les données ont été nettoyées et transformées avec Power Query avant leur analyse.

## 🔄 Étapes du projet

1. Importation des données
2. Nettoyage des données
3. Transformation des données avec Power Query
4. Fusion des différentes tables
5. Calcul des KPI
6. Analyse des ventes
7. Création des graphiques
8. Création du dashboard
9. Interprétation des résultats
10. Formulation de recommandations

## 📈 Analyses réalisées

* Analyse globale des ventes
* Analyse du chiffre d'affaires par ville
* Analyse du chiffre d'affaires par mois
* Analyse du chiffre d'affaires par produit
* Suivi des principaux KPI

## 💡 Principaux résultats

L'analyse a permis d'identifier :

| Dimension  | Meilleure performance |
| ---------- | --------------------- |
| 🏙️ Ville  | **Dakar**             |
| 📅 Mois    | **Août**              |
| 💻 Produit | **Ordinateur**        |

## 📊 Dashboard

Un tableau de bord Excel a été réalisé afin de présenter les principaux KPI et les différentes analyses de manière claire et visuelle.

Le dashboard permet notamment de suivre :

* le chiffre d'affaires ;
* le nombre de ventes ;
* les quantités vendues ;
* les performances par ville ;
* les performances par mois ;
* les performances par produit.
