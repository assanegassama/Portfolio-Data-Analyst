# Projet 5 — Analyse de la performance des boutiques

## Présentation du projet

Ce projet consiste à analyser la performance commerciale de plusieurs boutiques à l’aide de Power BI.

L’objectif est de transformer les données de ventes, boutiques, produits, clients, commerciaux et objectifs en indicateurs et visualisations permettant de mieux comprendre les performances commerciales.

Le dashboard permet notamment d’analyser le chiffre d’affaires, le nombre de ventes et l’évolution des performances selon les boutiques, les catégories et les périodes.

## Objectifs

- Analyser le chiffre d’affaires des boutiques
- Comparer les performances entre les boutiques
- Analyser le chiffre d’affaires par catégorie
- Suivre l’évolution du chiffre d’affaires dans le temps
- Suivre le nombre de ventes
- Faciliter la prise de décision grâce à un dashboard interactif

## Outils utilisés

- Power BI
- Power Query
- Excel
- DAX
## Sources de données

Le projet utilise plusieurs fichiers Excel servant de sources de données :

- Boutiques : informations sur les boutiques
- Produits : informations sur les produits et catégories
- Ventes : données relatives aux ventes réalisées
- Objectifs : objectifs commerciaux
- Commerciaux : informations sur les commerciaux
- Clients : informations sur les clients

Les données ont été préparées et exploitées dans Power Query avant leur utilisation dans Power BI.

## Analyses réalisées

Le dashboard permet notamment de réaliser les analyses suivantes :

### 1. Performance par boutique

Comparaison du chiffre d’affaires réalisé par chaque boutique afin d’identifier les boutiques les plus performantes.

### 2. Performance par catégorie

Analyse du chiffre d’affaires généré par les différentes catégories de produits.

### 3. Évolution du chiffre d’affaires

Suivi de l’évolution du chiffre d’affaires par mois afin d’identifier les tendances de performance.

### 4. Nombre de ventes

Suivi du nombre de ventes réalisées et analyse de leur évolution selon les filtres sélectionnés.

## Interactivité du dashboard

Le dashboard contient des segments permettant de filtrer les analyses, notamment par :

- Boutique
- Catégorie

Les graphiques et les indicateurs se mettent automatiquement à jour lorsque l’utilisateur sélectionne un filtre.
## Principaux résultats

L’analyse permet de :

- Identifier les boutiques générant le plus de chiffre d’affaires
- Comparer les performances commerciales entre les boutiques
- Identifier les catégories contribuant le plus au chiffre d’affaires
- Suivre l’évolution mensuelle du chiffre d’affaires
- Suivre le nombre de ventes
- Utiliser les filtres interactifs pour approfondir l’analyse

## Dashboard

Le projet contient deux pages principales :

### Vue d’ensemble

Cette page présente les principaux indicateurs de performance ainsi qu’un segment permettant de filtrer les résultats par boutique.

### Analyse des performances

Cette page permet d’analyser :

- Le chiffre d’affaires par boutique
- Le chiffre d’affaires par catégorie
- L’évolution du chiffre d’affaires par mois
- Le nombre de ventes

Des segments Boutique et Catégorie permettent d’explorer les données de manière interactive.

Ce projet montre comment Power BI peut être utilisé pour transformer plusieurs sources de données commerciales en un dashboard interactif et facilement exploitable.

L’analyse permet de suivre les performances des boutiques et d’aider les responsables à identifier les tendances et les points nécessitant une attention particulière.
